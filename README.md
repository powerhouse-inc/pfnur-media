# PFNÜR media

Public video assets for PFNÜR. Video files are distributed as GitHub Release assets.

The `expert-interview-v1` release contains:

- `short.mp4`: vertical summary, 576 × 1024, 156.1 seconds.
- `full.mp4`: full interview, 848 × 480, 1010.6 seconds.

Both files retain their original H.264/AAC encoding. Subtitle files are maintained separately by the portal.
